# Learning Projects

A personal repository for learning experiments and small projects. This README provides a minimal guide and a simple daily progress template so you can make small, meaningful updates each day.

## Purpose
Keep experiments, notes, and small projects in one place and record short daily progress entries so it's easy to track learning over time.

## Quick start
- Use one commit per small improvement or learning entry.
- Prefer descriptive commit messages (see "Commit convention" below).

## How to log daily progress
Add a short progress entry each day. You can either:
- Create a file named progress/YYYY-MM-DD.md (recommended for history), or
- Append an entry to a single PROGRESS.md file.

Use this template for each daily entry:

Date: YYYY-MM-DD

What I worked on:
- (1–2 short bullets)

What I learned:
- (key takeaways)

What I struggled with / open questions:
- (short notes)

Next steps:
- (small actionable item for the next session)

Commit convention example:
- progress: 2026-08-28 - Added daily learning notes about X
- docs: clarified README and daily progress template

## Contact / Notes
This repository is for personal learning — keep entries short and concrete so you can make progress every day.
